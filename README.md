# poof

A small, quiet browser with Arc-style spaces. Rust: `tao` + `wry` (WebView2) + an HTML sidebar.
Minimal, flat, no gradients, no emoji: every glyph in the UI is an icon.

## Run (Windows 10/11)

1. Install Rust (rustup.rs, MSVC toolchain) + Visual Studio Build Tools ("Desktop development with C++").
2. WebView2 Runtime installed and up to date (preinstalled on Win 11).
3. `$env:RUST_LOG="info"; cargo run`
   If you get type errors around `ICoreWebView2…`, align `webview2-com` / `windows` in Cargo.toml with
   `cargo tree -i webview2-com` and `cargo tree -i windows`.

Data lives in `%LOCALAPPDATA%\Poof\`. If you used the earlier ArcRS build, its folder is moved over on first launch,
so your pinned tabs, logins and extensions come with you.

First launch downloads AdBlocker Ultimate (needs internet) into `%LOCALAPPDATA%\Poof\extensions\`.
Remove it from the Extensions panel and it will not come back.

## Design

Everything visual reads from `ui/theme.css`.

- Your palette is pasted in verbatim at the top. Light mode uses the regular colors on beige, dark mode uses the
  "opp" colors on near-black. The UI only reads semantic tokens (`--ink`, `--stage`, `--chrome`, `--line` …), so
  retheming means editing that one file.
- Settings (gear, bottom right) has **System / Light / Dark**. System follows Windows live.
- Each space has one flat color. The sidebar tint, the space badge and the focus rings derive from it.
- Icons are [Lucide](https://lucide.dev) (ISC). `ui/icons.js` is generated by `node tools/gen-icons.mjs <lucide-static/icons>`;
  the generator includes the complete icon directory. Run it again after updating `lucide-static` to refresh the picker.
- Type is `Inter` if installed, otherwise Segoe UI Variable. Change `--f-text` / `--f-display` to use another face.

## Spaces

Click the space name (or the pencil) to edit it. The color picker works like Arc's: drag on the wheel, drag the
brightness slider, tap a palette color, or type a hex. The sidebar previews the color live as you choose.
Space icons can be searched by Lucide name, and sanitized SVG files can be uploaded. Old emoji icons from earlier
versions are replaced with a house icon. The sidebar can be collapsed from its top-left control; the setting persists.

## Pinning, favorites, order

Drag any tab across the **line** under the pinned tabs to pin it ("Release to pin" appears on the line). Drag a
pinned tab below the line to unpin it. Drag onto the favorites grid at the top to make a favorite. Dropping between
rows sets the order, and pinned order is remembered. Esc cancels a drag. The hover buttons (pin, star, close) still work.

## Extensions & store

- Puzzle icon (top of sidebar) → manage extensions: install by Web Store link or ID, remove, browse the store.
- On any Chrome Web Store detail page an **Add to poof** button appears in the address bar.
- Installs download the CRX from Google's update endpoint, unpack to `extensions\<id>\`, and load it
  into every profile through WebView2 `AddBrowserExtension`.
- Limits (WebView2, not fixable here): no toolbar icons/badges/popups; no auto-update (reinstall to update);
  extension IDs are path-derived, not the store IDs. Removal fully applies after restart.

## Start page (Ctrl+T)

Your most-visited sites first (local counts in state.json), then popular defaults. Type to search open tabs,
your sites, or the web (DuckDuckGo). Arrow keys + Enter.

## Developer tools

Press **F12** or **Ctrl+Shift+I**, or use the code icon in the toolbar to open the full Edge DevTools frontend docked inside Poof. The pane attaches to the active tab and can be docked left, right, top or bottom from Settings. Drag the divider inside DevTools to resize the inspector pane; its size is saved automatically. Device emulation places the inspected page in the main content area while keeping DevTools controls docked. Poof loads the DevTools frontend bundled with WebView2 using its `devtools://` scheme and connects it to the exact active page target through the profile's ephemeral loopback CDP endpoint. The endpoint is local to the machine and is not a separate server process. Its WebSocket origin check is relaxed for the embedded frontend, but the debugging server is still bound to loopback. It is unauthenticated, so other local processes can connect while that profile is running; loopback binding prevents LAN access but does not isolate it from software already running on the PC.
